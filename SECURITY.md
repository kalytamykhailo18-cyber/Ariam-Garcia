# Security Policy

## Reporting a Vulnerability

If you find a security issue in the site or the code, please email
**kalytamykhailo18@gmail.com** with the subject `SECURITY: ariam-garcia.vercel.app`.

Please include:

- A concrete description of the issue.
- Steps to reproduce (URL, HTTP request, browser).
- The impact you believe it has.
- Your preferred credit line for the fix (or "anonymous").

Expected response time: within 3 business days.

The public disclosure timeline is coordinated with the reporter — no
retaliation, no forced silence, no bounty program yet.

## Preferred languages

English, Spanish, Portuguese.
